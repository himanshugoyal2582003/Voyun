**Inspiration**  
We were inspired by the barriers many creators face in music production—lyricists without producers, singers without original content, and fans missing out on unique remixes. Voyun was born to bridge these gaps.

**What it does**  
Voyun is a modular music collaboration platform where lyricists, producers, and vocalists contribute independently. AI-powered mixing compiles these layers into complete songs, ready for instant sharing.

**How we built it**  
We built Voyun using React Native for a mobile-first frontend, Node.js with Firebase and Supabase for backend scalability, and integrated audio tools like FFmpeg and Web Audio API for seamless processing.

**Challenges we ran into**  
Synchronizing audio layers from different contributors and ensuring smooth AI mixing were complex. Designing an intuitive UX for modular collaboration also required multiple iterations.

**Accomplishments that we're proud of**  
We successfully built a working prototype that allows real-time collaboration and automatic song compilation. Early testers loved the remix flexibility and ease of use.

**What we learned**  
We learned how to architect scalable, asynchronous collaboration tools and how to balance creative freedom with technical constraints.

**What's next for Voyun**  
We plan to launch with music colleges and creator communities, introduce remix challenges, and expand our AI toolset for smarter mixing and mastering.
